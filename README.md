# 모션 연습장

레퍼런스 영상을 한 편씩 따라, 가상의 제품 광고로 다시 만든 모션그래픽 35편을 보여 주는 정적 웹사이트입니다. 영상은 모두 HTML과 GSAP 코드로 그렸고 HyperFrames로 구웠습니다(영상 생성 AI는 쓰지 않았습니다).

```
index.html      랜딩 페이지 (빌드 도구 없이 바로 열림)
media/v01.mp4   웹용 영상 35편 (1080p, 합계 약 97MB, 파일당 12MB 이하)
media/v01.jpg   썸네일 35장
.nojekyll       GitHub Pages가 파일을 그대로 내보내게 함
```

## GitHub Pages로 배포하기

1. 새 저장소를 만들고 이 폴더의 내용(`index.html`, `media/`, `.nojekyll`, `README.md`)을 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 고릅니다.
3. 1~2분 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 에서 열립니다.

로컬에서 확인할 때는 `index.html`을 더블클릭해도 되지만, 영상이 막히면 이 폴더에서 `python -m http.server`를 실행하고 `http://localhost:8000`을 여세요.

## 배포 전에 꼭 정할 것

- **GitHub Pages 사이트는 누구나 볼 수 있습니다.** 저장소를 비공개로 두어도, 유료 기업용 요금제가 아니면 사이트 자체는 공개됩니다.
- **원작자 곡이 들어 있던 22편은 이 공개판에서 소리를 뺐습니다**(페이지에서 회색 점 「무음」). 음악을 합성곡으로 새로 만들면 `media/` 의 해당 파일만 바꿔 올리면 됩니다.
- **레퍼런스 정보(참고 영상 · 제작자 · 원본 링크)는 이 판에 들어 있지 않습니다.** 승인한 사람에게만 보이는 기능은 claude.ai 판에서만 작동합니다. 정적 사이트에서는 진짜 접근 제어를 할 수 없기 때문입니다.
- 모든 제품·브랜드는 가상입니다. 실존 회사의 광고가 아닙니다.
